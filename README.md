# LINGO QUEST — MVP

A browser-based bilingual language-learning game built with HTML, CSS and vanilla JavaScript.

## Run
Open `index.html` in a modern browser. No build step, API key, server or subscription is required.

## Included
- Arabic/English interface switch with RTL/LTR layout
- Persistent progress using localStorage
- XP, levels, streak display, lessons and learning stats
- Seven playable mini-game modes
- Built-in vocabulary search, favorites and browser speech synthesis
- Learning worlds, daily challenges, achievements, sample leaderboard and settings
- Responsive desktop/mobile layout

## Notes
- The leaderboard contains fictional sample players.
- Speech uses browser text-to-speech where available; it is not speech recognition or pronunciation scoring.
- This is a front-end MVP. Accounts, cloud sync, server-side analytics, and real multiplayer rankings require a backend.
